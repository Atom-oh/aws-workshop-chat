# Workshop Chat guide

This branch contains only the static deployment and usage guide, published by GitHub Pages.

- Publishing branch: `gh-pages`, repository root (`/`).
- Public guide: https://www.atomai.click/aws-workshop-chat/
- Application source and AWS deployment configuration remain on `main`.
- For guide updates, branch from `gh-pages`, edit the static files, validate them, and open a PR back to `gh-pages`.
- Preview locally with `python3 -m http.server 8000` and open `http://localhost:8000`.

`assets/fonts/pretendard-LICENSE.txt` contains the license for the bundled font.
